# 0027 Widget: Shadow DOM isolation
Status: accepted. Problem: widget CSS/ids lived in the host page, so host styles could break it and its rules could leak out. Decision: render style + elements in an open shadow root on #bw-host (:host{all:initial}, border-box reset); existing #bw selectors keep working inside the root; feature-detect attachShadow and fall back to the old light-DOM path. Open mode keeps it testable. Security: no new inputs; text still via textContent. Rejected: closed mode (no benefit against hostile host page), iframe (extra request, sizing/focus issues). Not validated in real browsers.
