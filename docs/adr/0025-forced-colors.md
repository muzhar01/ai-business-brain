# 0025 Forced-colors (Windows High Contrast) support
Status: accepted. Research: MDN forced-colors (developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors): background-color/border-color/outline-color are replaced by system colours, box-shadow and non-url background-image are removed; authors should make small tweaks only, using system colour keywords. Decision: one small block at the end of app.css (no separate design) adding borders and system-colour states where meaning was carried by background only: buttons, current nav item, palette selection, find hits, chat bubbles (user dashed), pills, skip link, focus ring. forced-color-adjust is never set to none. Pill text already carries meaning. Not validated in a real Windows High Contrast browser.
