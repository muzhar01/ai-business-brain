# 0021 Accessibility audit test + automatic label pairing
Status: accepted. AccessibilityAuditTest renders every app page and checks lang/title/one main/one h1, unique ids, named buttons/links, labelled controls, resolvable aria references, plus CSS for WCAG 2.2 SC 2.4.11 (scroll-padding), 2.5.8 (24px targets) and prefers-contrast. It found ~85 adjacent <label>/<control> pairs with no association; instead of editing every view, a Blade precompiler (App\Support\LabelPairing) adds for/id with a per-render random id. Rejected: JS pairing (not present without script), editing 85 sites (large diff). Security: ids are random, no user input reaches the regex output. Not covered: contrast ratios, screen-reader behaviour.
