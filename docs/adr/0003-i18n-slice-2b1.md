# 0003 i18n slice 2b-1: leads and knowledge

Status: accepted. Follows ADR 0001/0002.
- Wrap leads and knowledge views with `__()`; stored values (lead status, document status) stay English, display via `__($status)`; statuses added to DYNAMIC_KEYS in I18nTest.
- Option `value=` set explicitly so translated labels never change submitted data.
- JS confirm/alert strings pass through `@js(__())` (hex-escaped, safe in attributes).
- The inline link sentence uses a placeholder so word order can flip in ur/ar; link built from `e()`-escaped parts, no `{!! __() !!}`.
- Icon-only buttons and placeholder-only inputs get aria-labels; labels get `for`.
- Security: no new input paths; all output escaped.
- Remaining: chat, agents, datasets, imports/exports, settings, billing, profile.
