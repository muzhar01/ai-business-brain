# 0029 Widget script: ETag + conditional GET
Status: accepted. Problem: widget.js is fetched on every customer page view; after the 300 s max-age it was re-downloaded in full. Decision: strong ETag (sha256 of rendered body), 304 on matching If-None-Match (weak prefix and lists tolerated), stale-while-revalidate 86400, Cross-Origin-Resource-Policy: cross-origin so strict host pages can embed it. Security: static public script, no per-user data in the body, so shared caching is safe. Rejected: minification build step (adds tooling for ~few KB). Not validated in real browsers/CDNs.
