# 0004 i18n slice 2b-2: chat and agents

Status: accepted. Follows ADR 0001-0003.
- Agents index/form and chat wrapped with `__()`; en/ur/ar catalogues extended.
- Chat JS strings come from one `const T = @js([...])` map (hex-escaped JSON), never string-concatenated into HTML unescaped; translated text is passed through `esc()`/`textContent`.
- Sentence with embedded UI path uses `:where` placeholder replaced after escaping, so word order can flip in ur/ar.
- Plurals/counts use placeholders (`:count actions`); trans_choice deferred to slice 3.
- Labels get `for`; search input gets aria-label. Stored values untouched.
- Security: no new input paths; all output escaped; T map is JSON-encoded by @js.
- Test scope: chat, agents/index, agents/form added to SCOPED_VIEWS; attribute-literal check ignores JS `${}` templates.
- Remaining: datasets, imports/exports, settings tabs, billing, profile, admin.
