# 0005 i18n slice 2b-3: datasets, imports (ETL), exports

Status: accepted. Follows ADR 0001-0004.
- Datasets index/show, import wizard (create, map, show, index) and exports wrapped with `__()`; en/ur/ar extended (~110 keys).
- Stored values (status, source_type, schedule, target) stay English; display goes through `__($value)`, keys registered as DYNAMIC_KEYS. Form option `value`s are explicit so posted values never depend on the language.
- Sentences with counts/targets use placeholders; the dataset blurb injects `<span class="mono">` after `e()`-escaping the translation, so markup cannot come from a catalogue.
- JS confirms use `@js(__())`. Every form control gets `for`/`id` or aria-label (mapping table inputs, dataset search); radio source group gets role=radiogroup; SQL textarea and credentials are `dir=ltr`/`autocomplete=off`.
- Security: no new input paths; output escaped; no behaviour change server-side.
- Remaining: settings tabs, billing, profile, admin; mails, numbers/dates, plurals.
