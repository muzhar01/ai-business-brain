# 0026 Widget: contrast-safe brand colour, dark scheme, forced colours
Status: accepted. Problem: widget text was always white on the tenant's brand colour (fails WCAG 1.4.3 for light colours), had no dark scheme and no forced-colors rules, and the input had outline:none (2.4.7). Decision: validate colour as #rrggbb, choose #000/#fff by WCAG contrast ratio in JS; add prefers-color-scheme:dark block; add forced-colors block with system colours (no hex, no forced-color-adjust:none); visible focus rings. Same techniques as ADR 0025. Rejected: Shadow DOM (separate slice). Not validated in real browsers.
